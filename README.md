I work mostly around Kubernetes and cloud-native tooling. I build platforms, wire up CI/CD, automate the boring parts, and try to keep releases predictable. I started on the application side and gradually moved towards infrastructure and reliability, which is where I spend most of my time now.

## What I work on

- **Kubernetes & containers:** day-to-day cluster work, Helm charts, GitOps with Argo CD
- **CI/CD:** build, test and release pipelines with GitHub Actions, GitLab CI and Jenkins
- **Automation & configuration:** Ansible, Bash and Python for the repetitive stuff
- **Observability:** Prometheus and Grafana for metrics, alerts and dashboards
- **Linux & networking:** Debian/Ubuntu servers, systemd, Nginx, iptables
- **Databases:** PostgreSQL, MongoDB, Oracle
