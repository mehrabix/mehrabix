I work mostly around Kubernetes and cloud-native tooling. I build platforms, wire up CI/CD, automate the boring parts, and try to keep releases predictable. I started on the application side and gradually moved towards infrastructure and reliability, which is where I spend most of my time now.

## What I work on

- **Kubernetes & containers:** Deployments, Pods and Services written as manifests to ship my own frontends and backends, plus multi-stage Docker builds and Compose
- **CI/CD & delivery:** build, test and release pipelines with Jenkins, GitLab CI and GitHub Actions, plus GitOps delivery with Argo CD
- **Build systems:** the tooling behind each stack I've delivered in — Maven and Gradle, MSBuild and NuGet, pyproject with hatchling, and npm/pnpm workspaces
- **Linux:** server operations, systemd, service configuration, processes, file systems, CLI
- **Databases:** PostgreSQL, SQL Server, Oracle, MongoDB, SQLite, and Redis for caching and session state
